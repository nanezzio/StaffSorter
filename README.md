# Employee Database (Тестовое задание)

Консольное приложение на C++ для управления базой данных сотрудников.

## Описание
Программа хранит информацию о людях (Person), местах работы (Job) и должностях (Position). 
Данные хранятся в `std::vector` (для людей) и `std::map` (для работ и должностей, с индексацией по ID).

Реализована сортировка списка сотрудников:
- По имени и фамилии (`std::stable_sort` + функция сравнения).
- По возрасту (лямбда-выражение).
- **По названию места работы** (с использованием функционального объекта/функтора для передачи дополнительных данных в сортировку).

## Технологии
- C++ (стандарт C++11 и выше)
- STL: `vector`, `map`, `algorithm`
